# trade-agent-profile

> **これは実験的な参照仕様です。いずれの標準化団体の公式仕様でもありません。**
> **This is an experimental reference specification. It is not an official specification of any standards body.**

The user makes the decisions. This tool only helps with preliminary checks and record keeping.

A trade profile for the AI agents of shippers, freight forwarders, customs brokers and banks: a shared data contract, message types and conformance tests on top of A2A (conversations between agents) and MCP (tools for AI). It does not invent a new protocol, and it runs no central server.

- Japanese README with all commands: [README.ja.md](README.ja.md)
- Specification (Japanese): [docs/PROFILE.md](docs/PROFILE.md)
- Mapping to existing standards such as DCSA and TradeTrust (Japanese): [docs/MAPPING.md](docs/MAPPING.md)
- Design rationale (Japanese): [docs/RATIONALE.md](docs/RATIONALE.md)
- Contributing: [CONTRIBUTING.md](CONTRIBUTING.md) / Security: [SECURITY.md](SECURITY.md)

All sample data is fictitious. The declaration draft is a mock and cannot be used for an actual customs declaration.
